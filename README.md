# Portuguese Colonists

![Portuguese Colonists](About/Preview.png)

**Olá! Bring Portugal to the Rim.**

Portuguese Colonists is a RimWorld mod that fills your world with Portuguese colonists, raiders and traders, and now and then a famous Portuguese face among them.

## Features

- **Portuguese names:** over 300 first names, 160+ last names and 180+ nicknames are added to the random name pool. Expect pawns like Gonçalo "Tremoço" Magalhães or Matilde "Varina" Sousa. Many nicknames come straight from Porto and Northern slang.
- **76 famous Portuguese figures:** kings and queens, navigators, poets, scientists, athletes, footballers, fadistas, comedians, TV hosts, and a few cult legends and oddballs. Each has a hand-written childhood and adulthood backstory. Like RimWorld's own famous characters, they occasionally show up as colonists, wanderers, traders or raiders. Will it be Afonso Henriques, Amália Rodrigues, Rui Nabeiro, or Cristiano Ronaldo shouting *SIUUU*?
- **Not overpowered:** famous figures get vanilla-level skill bonuses, so they're fun to find but don't break your game.
- **Translated:** every backstory is available in European Portuguese, which is also used when the game is set to Brazilian Portuguese.

👉 **See the full list of names and personas in [NamesInfo.md](NamesInfo.md).**

## Compatibility

- RimWorld **1.5** and **1.6**
- No dependencies, no Harmony
- **Safe to add to an existing save.** Removing it from a save where a famous figure has already appeared isn't recommended, because their backstories come from this mod.
- Portuguese names have the same chance as vanilla names, so your world gets a mix rather than only Portuguese pawns.

## Installation

1. Download the latest `PortugueseColonists-x.y.z.zip` from the [Releases](../../releases) page.
2. Extract it into your `RimWorld/Mods/` folder, so the path is `Mods/PortugueseColonists/About/About.xml`.
3. Enable **Portuguese Colonists** in the in-game mod list and restart.

When updating, delete the old `PortugueseColonists` folder before extracting the new one.
